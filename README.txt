Julio Ovalle - Bootstrap Cart

Open index.html in a web browser. An internet connection loads Bootstrap and the original demo images. Backup SVG images are included.

Click Add to Cart for any of the six products. Change quantities, remove items, or clear the cart. Subtotal, demo sales tax (8.25%), and total update immediately. Checkout is a demo and does not charge money.

Files:
index.html - Bootstrap page
style.css - Styling
script.js - Product array and shopping cart logic
assets/ - Backup product and slideshow pictures
